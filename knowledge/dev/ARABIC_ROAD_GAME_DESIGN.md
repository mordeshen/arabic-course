# 🚗 نوّطني — "נווט אותי" — משחק ניווט בערבית

## קונספט

משחק ניווט אינטראקטיבי שבו השחקן נוהג בכבישי ישראל ו**כל השלטים הם בערבית בלבד**.
השחקן צריך לקרוא שלטים, לבחור כיוונים, ולהגיע ליעד — תוך ניהול "דלק" ו"זמן".

> **למה זה עובד:** במקום תרגיל קריאה יבש, השחקן *צריך* את הערבית כדי להתקדם.
> הקריאה הופכת מ"משימה" ל"כלי הישרדות".

## מסכי משחק

### 1. מסך פתיחה
```
نوّطني 🚗
---------
שלום נהג! הGPS התקלקל.
הדרך היחידה שלך הביתה — לקרוא את השלטים.

[🟢 יאללה, נתחיל]
[⚙️ הגדרות]
```

### 2. בחירת מסלול (שלב = mission)
כל mission הוא מסלול מנקודה A לנקודה B עם 3-6 צמתים.

```
📍 משימה 1: "הדרך לים"
   מ: الناصره (נצרת) → ל: تل ابيب (תל אביב)
   צמתים: 3 | דלק: ⛽⛽⛽⛽⛽ | ⭐⭐⭐

📍 משימה 2: "דרום בלי GPS"
   מ: اورشليم (ירושלים) → ل: ايلات (אילת)
   צמתים: 5 | דלק: ⛽⛽⛽⛽⛽⛽⛽ | ⭐⭐⭐⭐

📍 משימה 3: "סיור בגליל"
   מ: كرميئيل (כרמיאל) → ל: الناصره (נצרת) דרך כפרים
   צמתים: 4 | דלק: ⛽⛽⛽⛽⛽⛽ | ⭐⭐⭐⭐⭐
```

### 3. מסך צומת (הליבה של המשחק)

```
┌─────────────────────────────────────┐
│                                      │
│    ⛽⛽⛽⛽🪫  דלק: 4/5              │
│    📍 אתה נמצא ב: ???              │
│    🎯 יעד: ايلات                    │
│                                      │
│  ┌──────────┐    ┌──────────┐       │
│  │ ← متسبي  │    │  ايلات → │       │
│  │   رمون   │    │          │       │
│  │  [40]    │    │  [40]    │       │
│  └──────────┘    └──────────┘       │
│                                      │
│     ↑ שלט אמיתי מהתמונות!          │
│                                      │
│  [⬅️ שמאלה]  [➡️ ימינה]  [💡 רמז]  │
│                                      │
└─────────────────────────────────────┘
```

**מכניקה:**
- שלט אמיתי (מתוך ה-JSON של התמונות) מוצג **רק עם הטקסט הערבי**
- השחקן בוחר כיוון: שמאל / ימין / ישר
- בחירה נכונה → מתקדם לצומת הבא, אנימציית נסיעה
- בחירה שגויה → מפסיד ⛽ דלק + "נסעת 20 ק"מ בכיוון הלא נכון!"
- לחיצה על 💡 רמז → מראה את התעתיק (transliteration) אבל עולה ⛽ חצי דלק

### 4. מסך "הגעת!"
```
🎉 وصلت! הגעת ל-ايلات!

⭐⭐⭐ 3/3 כוכבים
⛽ דלק שנשאר: 3/7
🧭 צמתים נכונים: 5/5
💡 רמזים: 1
📝 מילים חדשות שלמדת: 4

[🔄 שחק שוב]  [➡️ משימה הבאה]  [📖 חזור על המילים]
```

## מנגנוני משחק

### דלק (⛽) — המשאב המוגבל
| פעולה | עלות דלק |
|---|---|
| בחירה נכונה | 0 |
| בחירה שגויה | -1 ⛽ |
| שימוש ברמז (תעתיק) | -0.5 ⛽ |
| שימוש ברמז (תרגום מלא) | -1 ⛽ |
| בונוס: קריאה נכונה ב<3 שניות | +0.5 ⛽ |

**אם נגמר הדלק:** "נתקעת בצד הדרך! 🚗💨 תנסה שוב?"

### כוכבים (⭐) — הדירוג
- ⭐⭐⭐ = הגעת בלי טעויות ובלי רמזים
- ⭐⭐ = הגעת עם עד 2 טעויות או 2 רמזים
- ⭐ = הגעת (בקושי)

### מילים שנלמדו (📖)
אחרי כל משימה, מוצגות המילים החדשות שהשחקן פגש:
```
📖 מילים מהמסלול:
   الناصره = נצרת | ايلات = אילת | متسبي رمون = מצפה רמון
   🔊 [השמע] | 📝 [תרגל כתיבה]
```

## מסלולים מוצעים (מבוססים על השלטים שיש לנו)

### משימה 1: "הדרך לים" (Easy)
```
START: الناصره (נצרת)
  ↓ צומת 1: שלט כפר כנא/נצרת → בחר כיוון נצרת (חזור? או קדימה?)
  ↓ צומת 2: שלט תל אביב-יפו → בחר תל אביב
  ↓ צומת 3: שלט ירושלים/תל אביב → בחר תל אביב
END: تل ابيب-يافا ✅
```

### משימה 2: "דרום בלי GPS" (Medium)
```
START: اورشليم (ירושלים)
  ↓ צומת 1: שלט שדרות/מצפה רמון → בחר מצפה רמון (דרום)
  ↓ צומת 2: שלט מצפה רמון/אילת → בחר אילת
  ↓ צומת 3: שלט כרם שלום/אילת → בחר אילת (לא כרם שלום!)
END: ايلات ✅
```

### משימה 3: "סיור בגליל" (Hard)
```
START: كرميئيل (כרמיאל)
  ↓ צומת 1: שלט כפר כנא/נצרת → בחר כפר כנא
  ↓ צומת 2: שלט נצרת/תל אביב → בחר נצרת
  ↓ צומת 3: שלט עתיר ידע/נצרת → בחר נצרת (לא אזור תעשייה!)
  ↓ צומת 4: שלט נצרת → הגעת!
END: الناصره ✅
```

### משימה 4: "מהגולן לדרום" (Expert)
```
START: مروم جولان (מרום גולן)
  ↓ צומת 1-6: מסלול ארוך דרך כל השלטים
END: كيرم شالوم (כרם שלום)
```

## מצב "מהיר" — بسرعة!

משחק מהיר בלי ניווט: שלטים מופיעים אחד אחרי השני, 10 שניות לכל שלט.
- שלט מופיע (רק ערבית)
- טיימר רץ ⏱️
- השחקן מקליד את שם היישוב
- נכון = נקודות (יותר מהר = יותר נקודות)
- לא נכון = השלט מתגלה עם הסבר

```
⏱️ 07:32
┌────────────────┐
│  كفر كنا       │
│    [754]       │
└────────────────┘

מה כתוב? [____________] [✓]

✅ כפר כנא! +8 נקודות (3.2 שניות)
📖 كفر = כפר | كنا = כנא
```

## מצב "בנה שלט" — اكتب اللافتة

**משחק הפוך!** השחקן מקבל שם יישוב בעברית וצריך לבנות את השלט בערבית.

```
🏗️ בנה שלט ל: נצרת

גרור אותיות:  ا ل ن ص ر ه ة

[___] [___] [___] [___] [___] [___]

💡 רמז: מתחיל ב-ال (אל הידיעה)

✅ الناصره — מעולה! 
```

**אותיות מוצעות:** ערבוב של אותיות נכונות + כמה מסיחות.
**רמות:**
1. **קל:** 3-4 אותיות + 1 מסיח
2. **בינוני:** 5-6 אותיות + 2 מסיחים
3. **קשה:** 7+ אותיות + 3 מסיחים, בלי רמזים

```javascript
// מציג תמונת שלט עם מסכות CSS

function SignDisplay({ sign, revealHebrew, revealEnglish }) {
  return (
    <div className="sign-container" style={{ position: 'relative' }}>
      <img src={sign.image_file} />
      
      {!revealHebrew && sign.masks.hebrew && (
        <div className="mask" style={{
          position: 'absolute',
          left: `${sign.masks.hebrew.x_pct}%`,
          top: `${sign.masks.hebrew.y_pct}%`,
          width: `${sign.masks.hebrew.w_pct}%`,
          height: `${sign.masks.hebrew.h_pct}%`,
          background: 'rgba(40,40,40,0.92)',
          backdropFilter: 'blur(8px)',
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
        }}>
          <span>❓</span>
        </div>
      )}
      
      {/* same for English mask */}
    </div>
  );
}
```

## עיצוב ותחושה

### פלטת צבעים
- רקע: גרדיאנט של מדבר/כביש (#1a1a2e → #16213e)
- שלטים: ירוק כביש (#006B3F) / לבן (#ffffff)
- דלק: צהוב-כתום (#FFA500)
- הצלחה: ירוק (#4CAF50)
- שגיאה: אדום רך (#E57373)
- ערבית: Noto Sans Arabic, גדול וברור

### אנימציות (prefers-reduced-motion friendly)
- מסכה מתגלה: fade-out 0.6s + scale קל
- מעבר צומת: slide-in מהצד
- דלק יורד: shake קל + צבע משתנה
- הגעה ליעד: confetti קל + اهلا وسهلا!

### RTL
- כל הממשק RTL (direction: rtl)
- טקסט ערבי: font-size גדול (24px+)
- Heebo לעברית, Noto Sans Arabic לערבית

## הרחבות עתידיות

1. **שלטים מהרחוב:** השחקנים מצלמים שלטים אמיתיים ומוסיפים למשחק
2. **מצב דו-שחקנים:** מי מגיע ראשון ליעד?
3. **שלטי חנויות:** לא רק כבישים — גם שלטי חנויות, מסעדות, מודעות
4. **מצב שמע:** שומעים את השם בערבית מדוברת ומזהים את השלט
5. **אינטגרציה עם הקורס:** מילים מהמשחק נכנסות אוטומטית ל-knowledge base של הקורס
