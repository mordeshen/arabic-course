# Palestinian Arabic Course - Project Root

## Structure
- `app/` — The course application (HTML lessons, game data, index)
- `knowledge/arabic/` — Arabic language reference (dictionary, grammar, transcripts, dialects)
- `knowledge/dev/` — Development docs (instructions, specs, design docs)
- `rag-resources/` — RAG pipeline resources (skill file, corpus builder, parser)
- `assets/sign-images/` — Road sign images for the game

## Key Files
- `app/index.html` — Course entry point
- `knowledge/dev/CLAUDE_CODE_INSTRUCTIONS.md` — Main dev instructions
- `knowledge/dev/NAWWITNI_DEV_INSTRUCTIONS.md` — Nawwitni game specs

## Rules
- All file paths in English only
- No spaces in file/folder names
- Read `knowledge/dev/CLAUDE_CODE_INSTRUCTIONS.md` before any code changes
